## 💡 The Problem: The AI Assumption Blindspot

When AI dev agents (like IBM Bob) generate or refactor code across multiple files, they produce clean, syntactically elegant code that passes happy-path unit tests. However, AI models suffer from **unwritten assumption blindspots**:

1. **Boundary Blindspots:** Assuming amounts or quantities are always positive (`amount > 0`), enabling credit duplication exploits.
2. **Multi-Tenant Blindspots:** Omitting organizational workspace checks, allowing cross-tenant data leaks.
3. **Concurrency & Race Conditions:** Non-atomic read-modify-write state changes that collapse under burst traffic.
4. **Idempotency Neglect:** Omitting replay tracking, causing duplicate debiting on network retries.

Because human reviewers are overwhelmed by large AI-generated diffs, these PRs are frequently rubber-stamped.

## ⚡ Key Capabilities

* **Ghost Assumption Mining:** Detects subtle implicit invariants across Boundary, Concurrency, Tenant Isolation, and Idempotency dimensions.
* **Adversarial Execution Sandbox:** Runs synthesized pytest test vectors in real time, exposing hidden stack traces and failures on camera.
* **Service Topology & Blast Radius:** Maps which databases, third-party APIs (e.g. Stripe), and messaging queues are directly or secondarily exposed to mutation.
* **Autonomous Self-Healing Loop:** Automatically provides failure traces back to IBM Bob to synthesize and verify hardened zero-trust patches.
* **Cryptographic Resilience Passport:** Generates an in-toto / DSSE-compliant attestation and Markdown badge for GitHub Pull Requests.

## 🚀 Quickstart Guide

### Prerequisites
* Python 3.10+
* Node.js 18+ and npm
* Git

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/axiom.git
cd axiom
```

### 2. Start the Backend API (FastAPI)
```bash
cd backend
python -m pip install -r requirements.txt
python main.py
```
*Backend runs at `http://127.0.0.1:8000`*

### 3. Start the Frontend Dashboard (React + Vite)
```bash
cd ../frontend
npm install
npm run dev
```
*Frontend runs at `http://localhost:5173`*
